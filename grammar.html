🔄 N5・N4 動詞與形容詞形變中心

N4 文法大量使用「普通形」， 所以這裡不是只背 ます形，而是把各種變化連在一起理解。

① 丁寧形 ↔ 普通形

時態 丁寧形 普通形
現在肯定 行きます 行く
現在否定 行きません 行かない
過去肯定 行きました 行った
過去否定 行きませんでした 行かなかった
💡 N4 很多句型，例如 「～と思います」「～かもしれません」 前面都會大量使用普通形。 所以普通形是從 N5 進入 N4 的重要橋樑。

② 五段動詞：て形／た形

う・つ・る → って／った
買う → 買って → 買った
待つ → 待って → 待った
帰る → 帰って → 帰った
む・ぶ・ぬ → んで／んだ
飲む → 飲んで → 飲んだ
遊ぶ → 遊んで → 遊んだ
死ぬ → 死んで → 死んだ
く → いて／いた
書く → 書いて → 書いた
ぐ → いで／いだ
泳ぐ → 泳いで → 泳いだ
す → して／した
話す → 話して → 話した
⚠️ 特別注意：行く 不變成「行いて」， 而是 行って／行った。

③ 一段動詞

基本方法：去掉最後的「る」再接需要的形式。

食べる → 食べます
食べる → 食べない
食べる → 食べて
食べる → 食べた

見る → 見ます
見る → 見ない
見る → 見て
見る → 見た

④ 不規則動詞

原形 ます形 ない形 て形 た形
する します しない して した
来る 来ます 来ない 来て 来た

⑤ い形容詞

形式 高い
現在肯定 高い
現在否定 高くない
過去肯定 高かった
過去否定 高くなかった
⚠️ 「いい」是特殊變化：
いい → よくない → よかった → よくなかった

⑥ な形容詞與名詞

形式 静か 学生
現在肯定 静かだ 学生だ
現在否定 静かではない 学生ではない
過去肯定 静かだった 学生だった
過去否定 静かではなかった 学生ではなかった
